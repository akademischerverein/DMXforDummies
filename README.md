# DMXforDummies

**Abgelöst durch [Lichtorgel](https://github.com/akademischerverein/lichtorgel).**
DMXforDummies wird nicht mehr weiterentwickelt.

DMXforDummies hat das Licht im Vereinsraum des Akademischen Vereins
geschaltet: Farben und Szenen per sACN an den `dmx-sacn-server`. Lichtorgel
übernimmt das und mehr: Es schaltet die Bereiche aus, weiß, in Farbe oder auf
Party und lässt das Licht im Takt der Musik laufen, die der PC spielt.

Wie man Lichtorgel installiert, steht in dessen README unter „Installieren“.
